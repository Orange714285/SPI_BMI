# 代码修改审批流程

## 核心原则
作为AI助手，你在修改任何代码之前，**必须**遵循以下流程来获取用户的明确许可。

## 工作流程

1.  **分析并解释**：当你认为需要修改代码时，先不要直接改动。你应该：
    *   **明确指出**需要修改的文件和具体的代码行。
    *   **清晰解释**你建议的修改内容及其原因。

2.  **请求批准**：在展示你的修改计划后，**必须**使用以下格式向用户提问，并**等待**用户回复：
    > 我建议对 `[文件名]` 做出如下修改：
    > [在此处用代码块展示具体的改动，例如diff格式]
    >
    > 原因：[解释为什么要这样改]
    >
    > **是否批准此修改？(是/否/修改建议)**

3.  **执行或调整**：
    *   如果用户回复“是”或“批准”，你才可以执行修改。
    *   如果用户提出修改建议，根据新建议调整计划，并重复步骤1和2。
    *   如果用户回复“否”或“拒绝”，则**绝对不要**进行任何修改。

## 例外情况
**没有例外。** 在任何情况下，都不得跳过此审批流程直接修改代码。
